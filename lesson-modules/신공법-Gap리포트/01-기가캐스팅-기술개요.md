# 기가캐스팅(Giga Casting) 기술 개요

## 정의

6,000톤 이상 초대형 고압 다이캐스팅(HPDC) 장비로, 수십~수백 개 부품을 **단일 알루미늄 일체형 주조물**로 생산하는 공법.
Tesla가 2020년 Model Y에 최초 양산 적용.

## 핵심 원리

```
알루미늄 합금 용해 (700°C) 
→ 금형 주입 (속도: 10 m/s, 투입량: 80 kg)
→ 충전·고화 (사이클: 80~90초)
→ 레이저 트리밍 → X선 검사 → CNC 가공
```

## 기술 진화 단계

| 세대 | 장비 규모 | 주요 적용 |
|------|----------|----------|
| 1세대 | 4,000T | 언더바디 |
| 2세대 | 6,000~9,000T | 배터리 하우징 통합 |
| 3세대 | 12,000~16,000T | 차체 일체형 |
| 차세대 | 20,000T (개발 중) | 완전 차체 일체화 |

## 핵심 성능 수치

- **부품 통합**: Tesla Model Y 171개 → 2개 / Xpeng 300개 → 1개 / Volvo 33개 → 1개
- **원가 절감**: 20~40% (후방 구조물 기준, 40%는 Tesla 주장)
- **노동력 절감**: 65%
- **바닥 면적**: 47% 감소
- **금형 비용**: ~150만 달러 (약 20억원)
- **금형 수명**: ~100,000 shot (스탬핑 금형 600만개 대비 단명)

## 주요 한계

- 불량률 ~15% (스탬핑 1% 대비 높음) ⚠️
- 초기 CAPEX $7~8M (약 100억원)
- **oxide bifilm** 결함: 게이트 속도 30~45 m/s 고속 주입 → 산화물 혼입 → 피로강도 저하
- 부품 손상 시 전체 교체 필요 (수리비 급등)
- 수리 비용 급등 → 보험사/정비사 반발

## CAE 해석 주의사항

- 기가캐스팅 부품은 **위치별 물성 편차** 큼 → 단순 균일 물성 FEM 불적합
- 권장: 확률론적 피로해석 (probabilistic fatigue analysis)
- 안전계수 권장: **3.0 이상** (산포 대응)
- 인장강도: 170~250 MPa (핫스탬핑 800~2,000 MPa 대비 낮음)
