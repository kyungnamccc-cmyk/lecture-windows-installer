# 성우하이텍 기가캐스팅 Gap 분석 및 대응 방향

## Gap 요약표

| Gap 항목 | 현재 역량 | 기가캐스팅 요구 수준 | Gap 크기 |
|----------|---------|---------------------|---------|
| **핵심 공정** | 핫스탬핑·롤포밍·TWB (강판 중심) | 초대형 HPDC 6,000T+ | ★★★★★ 매우 큼 |
| **알루미늄 역량** | BCA 조립·개발 초기 (2018~) | 비열처리 고연성 합금 독자 주조 | ★★★★☆ 큼 |
| **CAE 역량** | 강판 구조해석 (응력·안전계수 판정) | 알루미늄 주조 결함 기반 확률론적 피로해석 | ★★★★☆ 큼 |
| **설비 규모** | 중소형 스탬핑 프레스 | 6,000T+ 초대형 다이캐스팅 ($7M+) | ★★★★★ 매우 큼 |
| **품질 검사** | 강판 검사 체계 | 인라인 X선 + AI 주조 결함 탐지 | ★★★☆☆ 중간 |

## 단계별 실행 로드맵

```
[단기 2026-2027]
▶ BSA 완제품 수주 확대 (크레타EV + 추가 신규)
▶ 기가캐스팅 후공정 파트너십 타진 (현대차 하이퍼캐스팅 공장 협력)
▶ 삼기 기술 협력 또는 수주 연계 검토

[중기 2027-2029]
▶ CAE 역량을 알루미늄 주조로 확장 (확률론적 FEM 도입)
▶ 정부 R&D 과제 참여 (KATECH, 현대차 협력)
▶ 알루미늄 다이캐스팅 후공정 기술 내재화

[장기 2030+]
▶ 파일럿 기가캐스팅 설비 도입 여부 판단 (시장 성숙 후)
▶ 한국 알루미늄 다이캐스팅 시장 공략 (2033년 21.8억 달러 목표)
```

## CAE 담당자 유의사항 (윤용식)

> 현재 CAE 판정 기준(응력 > 500 MPa → 불합격, 안전계수 < 2.0 → 불합격)은 핫스탬핑 강판 기준.
> 기가캐스팅 알루미늄 부품 해석 시:
> - 인장강도 기준값 변경 필요 (170~250 MPa 범위)
> - 안전계수 기준 상향 권장 (3.0 이상)
> - 위치별 물성 편차 고려한 확률론적 FEM 적용 검토
